# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用 localStorage 保存数据。

## 质保尾款

完工维修必须登记**实付金额**和**师傅**，系统从实付款预留两成尾款，完工三十天后结清。

- **待放款**：质保期内（完工起 30 天），到期无复发即可放款结清。
- **冻结**：质保期内同位置再报修，原尾款自动冻结并挂到返修单；返修未结前不能放款。返修完成后解冻，尾款继续等到期。
- **扣减**：师傅放弃返修时，填写返修支出，从尾款中扣减（支出 ≥ 尾款则全额抵扣），余额结清。
- **结清**：到期无复发直接放款，或扣减后发放余额。

列表支持按四类尾款状态筛选，顶部汇总待放款、冻结、扣减、结清金额。旧记录与未完工记录按**无质保**处理（显示"旧记录 · 无质保尾款"），可对旧完工记录补录实付后开启质保。

代码按职责分三层维护：

- `src/warranty.js`：尾款计算与质保状态流转（纯函数，不碰 DOM/存储）。
- `src/migrate.js`：localStorage 读写与旧版数据升级（`version: 2`）。
- `src/main.js`：页面展示与交互。
