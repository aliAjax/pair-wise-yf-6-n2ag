第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

## 质保尾款（第二版）

完工不再只记状态：完工时填写**实付金额**和**师傅**，自动从实付款扣留 **两成**作为质保尾款，**30 天**后到期。

尾款状态与规则：

- **待放款**：完工后默认状态。质保期内同位置再报修可登记返修；到期当天若无复发即可手动放款结清。
- **冻结**：质保期内同位置再报修，原尾款冻结并转到返修单；返修未结前不能放款。
  - 返修完成（师傅修好）：尾款解冻，从返修完成日重新计 30 天。
  - 师傅放弃（另请他人）：按返修实际支出从尾款扣减（超出尾款最多扣完），余额结清，状态为「已扣减」。
- **已结清**：到期无复发，尾款全额放给师傅。
- **旧记录**：按无质保处理，卡片标注「无质保」，不补算尾款。

列表第二行筛选条可按 待放款 / 冻结 / 扣减 / 结清 / 无质保 查看；顶部台账汇总四类金额与笔数。

### 代码结构（三块分开维护）

| 文件 | 职责 |
| --- | --- |
| `src/warranty.js` | 尾款计算与状态流转（两成、30天到期、冻结/解冻/扣减/结清），纯函数无 DOM |
| `src/migrate.js` | localStorage 数据升级（v1 → v2，旧记录补结构、标记无质保，幂等） |
| `src/view.js` | 页面展示（卡片、质保徽标、台账、筛选），只渲染 HTML 字符串 |
| `src/main.js` | 编排：表单、弹窗、事件，调用上面三个模块 |
